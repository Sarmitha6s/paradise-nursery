# Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application built with React. Users can browse houseplants, view plant details, add plants to a shopping cart, update quantities, remove products, and view the total cost.

## Features
- Landing page with a nursery background
- Plant listings grouped into three categories
- Add-to-cart functionality
- Dynamic shopping cart count
- Increase and decrease quantities
- Remove items from the cart
- Automatic subtotal and total cost calculation
- Continue shopping and checkout buttons

## Technologies Used
- React
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- React Router DOM
- Vite

## Run the project
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.
